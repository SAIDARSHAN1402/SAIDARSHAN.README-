## 📌 Featured project: Student Skill Development Tracker (SSDT)

**Problem:** Marks alone don't show a student's strong and weak skill areas, so students struggle to know what to improve next.

**Solution:** A web app where students register, assess six skills (Python, Machine Learning, AI, SQL and Databases, Web Development, Problem Solving and Algorithms), track progress and receive improvement suggestions, with optional AI-written wording through the Groq API.

**Architecture:** `React (Vite)` → `FastAPI backend` → `PostgreSQL (via SQLAlchemy)`

**My contribution (backend):**
- Built the REST APIs with Python and FastAPI
- Wrote the logic that analyses assessment results
- Integrated the backend with the React frontend
